Follow the given instructions:-
1. the files folder contain a app.py
2. the pre-requisites to run that app.py (which acts as our python flask backend) are: python and flask installed in your host device 
3. python can be installed from their official website 
4. after installing python run this command in the terminal in windows to install flask: pip install flask
5. after successful installation of python and flask, open terminal in the files folder and paste the given command to run the app.py file: python app.py
6. for opening the webpage, all the devices (host, client, mobile) must be connected to the same wifi network
7. after ensuring that all devices are connected to the same wifi look for this type of line in the terminal which will be printed by flask: Running on http://192.168.x.x:5000/
8. copy the url visible in your terminal (the line would be like the one in the above example line) by flask and paste in the browser of whatever device you want to access the webpage from
9. all set. use the webpage, test it as you wish
